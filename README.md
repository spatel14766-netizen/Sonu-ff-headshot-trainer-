# Sonu FF Headshot Trainer

An Android Studio starter project for an offline aim-practice simulator.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder as a project.
3. Let Android Studio download the Android Gradle plugin and SDK components.
4. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. The debug APK will be in `app/build/outputs/apk/debug/app-debug.apk`.

This is a standalone practice simulator. It does not connect to, modify, or automate Free Fire.
